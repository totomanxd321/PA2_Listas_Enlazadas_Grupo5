# Actividad 3: selección de estructura

| Situación | Estructura | Justificación técnica |
|---|---|---|
| Registro de acciones recientes para revertir cambios | **Pila** | Se revierte primero la última acción registrada (LIFO). |
| Atención de solicitudes en orden de llegada | **Cola** | Se atiende primero a quien llegó primero (FIFO), sin saltos. |
| Procesamiento donde el último ingresado se atiende primero | **Pila** | Es la definición de LIFO: acceso solo por el tope. |
| Flujo de espera de trámites pendientes | **Cola** | Los trámites esperan su turno en el orden en que ingresaron. |
